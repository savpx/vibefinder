# Vibe Finder

> Find your vibe.

**Live:** [vibefinder.tech](https://vibefinder.tech)

## Как это работает

1. **10 вопросов** о настроении, энергии, темпе и желании.
2. **Подбор вайба** из 14 атмосфер по взвешенному скорингу.
3. **Погружение** — свой фон, описание, цитаты и мини-игра.
4. **Шаринг** — у каждого вайба есть ссылка для друзей.

## Атмосферы

Затерянный в космосе · Заряженный · Неоновый · Уединенный · Ночной ·
Меланхоличный · Дзен · Хаотичный · Позитивный · Загадочный · Вдохновленный ·
Природный · Ностальгический · Ламповый

## Мини-игры

Полноценно доступен «Ночной» вайб: тетрис с цитатами и перезапуском.
Остальные атмосферы пока помечены как находящиеся в разработке.

## Языки

- Русский (по умолчанию)
- English

Переключение — в меню профиля, выбор запоминается в `localStorage`.

## Доступность

- Навигация с клавиатуры.
- Уважает системную настройку «уменьшить движение»
  (`prefers-reduced-motion`), а также принудительные режимы
  `?motion=off` и `?motion=on`.
- Контрастный текст, адаптив для телефонов, планшетов и десктопа.

## Производительность

- Звёздное небо рисуется на canvas и полностью останавливается,
  когда активен экран результата или вкладка скрыта.
- Тетрис работает на таймере падения вместо кадра за кадром,
  перерисовывая поле только при реальном изменении.
- Логотип предзагружается, шрифты подключены в WOFF2 с fallback.

## Структура

```text
index.html            разметка всех экранов
css/style.css         дизайн-система, темы вайбов, анимации
js/app.js             сценарии экранов, опрос, тетрис, шаринг
js/sky.js             canvas-анимация звёздного неба
js/intro.js           кинематографичная заставка
js/i18n/index.js      русско-английский каталог строк
js/data/*.js          вопросы, темы, скоринг
```

## Стек

- HTML, CSS, нативный JavaScript (ES-модули)
- Без фреймворков, сборщиков и зависимостей
- Статический сайт, раздаётся из корня репозитория
