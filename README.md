# Vibe Finder

> Find your vibe.

**Vibe Finder** — атмосферный сайт, который помогает назвать своё настроение. Ответь на 10 коротких вопросов — и получи вайб, который тебе подходит: со своим цветом, цитатой, звуком и мини-игрой.

**Live:** [vibefinder.tech](https://vibefinder.tech)

## Как это работает

1. **10 вопросов** о настроении, энергии, темпе и желании.
2. **Подбор вайба** из 14 атмосфер по взвешенному скорингу.
3. **Погружение** — свой фон, описание, цитаты и мини-игра.
4. **Шаринг** — у каждого вайба есть ссылка для друзей.

Без регистрации и установки — всё работает в браузере.

## Мини-игры

Каждый вайб — своя небольшая игра: созвездие, сбор солнечных искр, неоновый ритм, ловля листьев и капель, ночная прогулка, дыхание воды, поиск звёзд, раскраска, аркадный раунд, уютная комната, ASMR-клавиатура.

## Языки

Переключение — в меню профиля, выбор запоминается.

## Звук

Мягкие клики интерфейса, звук перехода и ASMR-клавиши. Воспроизведение стартует после первого взаимодействия — это правило браузеров.
